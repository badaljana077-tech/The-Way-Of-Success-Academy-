## 📂 Update Content (No Coding!)

All content lives in the `/content/` folder as simple JSON files:

| File | What it controls |
|------|-----------------|
| `content/hero/hero.json` | Homepage banner, stats |
| `content/current-affairs/weekly.json` | Weekly current affairs |
| `content/current-affairs/daily.json` | Daily current affairs |
| `content/notifications/notifications.json` | Exam notifications |
| `content/courses/batches.json` | Course batches |
| `content/routine/routine.json` | Class timetable |
| `content/youtube/videos.json` | YouTube videos |
| `content/mock-tests/mock-tests.json` | Mock test series |
| `content/testimonials/testimonials.json` | Student testimonials |
| `content/faculty/faculty.json` | Faculty profiles |
| `content/contact/contact.json` | Contact details |
