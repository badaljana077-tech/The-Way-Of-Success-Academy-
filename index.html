Setup & Configuration
Connect your Google Drive folders

📁 How to Set Up Google Drive Folders

  1. Go to Google Drive and create folders for each subject and each year
  2. Right-click a folder → Share → set to Anyone with the link can view
  3. Copy the Folder ID from the URL:
    drive.google.com/drive/folders/FOLDER_ID_HERE
  4. Paste each ID in the fields below and click Save Configuration

📊 How to Set Up Google Sheet for MCQ

  1. Open Google Sheets and create a new sheet
  2. Add these exact column headers in Row 1:
    Question  |  A  |  B  |  C  |  D  |  Answer  |  Subject
    Answer column: put the correct option letter — A, B, C, or D
    Subject column: gk / gs / ca / math / english
  3. Fill in your MCQ data from Row 2 onwards
  4. Click File → Share → Publish to web
  5. Choose Sheet1 and format Comma-separated values (.csv) → Click Publish
  6. Copy the URL. It looks like:
    https://docs.google.com/spreadsheets/d/SHEET_ID/pub?output=csv
  7. Copy only the SHEET_ID part and paste it below
